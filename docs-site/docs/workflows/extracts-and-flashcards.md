# Extracts and flashcards

An **extract** is material you may want to read or refine again. A **flashcard** is a prompt you want to answer from memory. Do not make the distinction based only on length.

## Capture options

**Extract selection** and **Flashcard from clipboard** remain direct commands. The other capture actions are grouped under **Capture or create…**; inline export is under **Advanced tools…**.

- **Extract selection** creates an extract from selected Markdown text.
- **Extract from clipboard (PDF-aware)** creates a linked extract from copied content.
- **Flashcard from clipboard** creates a card for the selected Toolkit, Anki, or Spaced Repetition backend.
- **Flashcard: name this image** creates a visual prompt.
- **Occlusion: create cards from image** creates cards that hide selected regions.
- **Export inline cards to selected card system** recognizes `Q:: … ::A::`, `{{c1::…}}`, and configured highlight forms.

## Choose where cards live

Use **Settings → Incremental Reading Toolkit → Flashcards → Create cards with**. Toolkit-owned cards join mixed sessions and use the built-in FSRS review window. Anki cards use Reuseman Flashcards' `#card`, `#card-reverse`, and highlighted-cloze syntax, sync to the `cards-deck` target, and are reviewed in Anki. Spaced Repetition remains available for existing vaults and SR cards.

Changing the choice affects new cards only. Each note records its backend so existing schedules keep working.

## A useful rule

Extract first when context still matters. Make a card only when you can write a specific prompt with a stable answer. One strong card is better than five copied sentences.
