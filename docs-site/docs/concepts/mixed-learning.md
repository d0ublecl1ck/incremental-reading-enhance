# Mixed learning

The Toolkit deliberately keeps card ownership explicit:

- **Topics** (`source` and `extract`) are chosen and rescheduled by Incremental Reading Toolkit.
- **Cards** are Markdown notes owned by the Toolkit, Anki, or Spaced Repetition.

**Build today's session queue** alternates reading topics with Toolkit and Spaced Repetition card notes. **Next element** opens the following saved path and starts the card's stored reviewer. Anki cards remain in Anki's review queue.

Each card records its backend. Toolkit cards use readable Markdown and scheduling frontmatter; Anki and Spaced Repetition cards use those plugins' native note forms.
