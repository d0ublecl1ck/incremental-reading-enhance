# 渐进阅读工具包用户指南

本指南从一个很小的日常流程讲起。开始使用前，你不需要把每个命令都配置好。

## 开始之前

1. 安装并启用 **渐进阅读工具包（中文版）**。
2. 在 **Flashcards** 分区选择 **工具包（内置）** 或 **通过 Flashcards 使用 Anki**。已有工作流可以继续使用 **Spaced Repetition（兼容）**。
3. 如果用 Anki：安装 Reuseman 的 Flashcards 与 AnkiConnect，并在 Flashcards 设置里授权；如果用 Spaced Repetition：安装 Spaced Repetition 插件。
4. 点击 **运行配置检查**，确认受管路径，并在 **通用** 中选择日期格式。

更改日期格式会迁移已有的排期字段、检查点、仪表盘日期与复习日志日期。

在设置页顶部点击 **打开用户指南**，或从 **打开工具包视图…** 中选择 **用户指南**，即可在 Obsidian 内查看快速上手与推荐快捷键。插件的 **帮助** 动作会直接打开项目 README。

## 五分钟快速上手

1. 打开 **捕获或创建…**，选择 **导入剪藏（当前笔记）** 或 **新建来源**，创建一个书籍、PDF、文章或视频来源。
2. 运行 **构建今日会话队列**，然后用 **下一元素** 打开队列中的下一项。
3. 只读有用的那一部分，不必强求读完整个来源。
4. 选中重要段落并运行 **摘录选中内容**。如果是 PDF：复制该段落后打开 **捕获或创建…**，选择 **从剪贴板摘录（支持 PDF）**。
5. 把光标留在你停下的位置。运行 **为当前阅读主题评级**，选择是否更新阅读位置，再选择主题节奏。准备好后再单独运行 **下一元素**。
6. 当某段内容值得变成长期记忆时，复制它并运行 **从剪贴板制作卡片**。
7. 继续用 **下一元素** 进行主题与卡片混合的会话。工具包卡片会打开内置复习窗口；已有的 Spaced Repetition 卡片会打开 Spaced Repetition；Anki 卡片在 Anki 中同步与复习，不进入工具包队列。

学习队列会把来源/摘录与可在本地复习的卡片笔记交替排列。主题排期使用 A 因子；工具包卡片使用内置 FSRS；导出到 Anki 与 Spaced Repetition 的卡片由各自系统负责排期。

## 设置快捷键

Obsidian 把快捷键称为 hotkeys。

1. 打开 **设置 → 快捷键**。
2. 搜索 `渐进阅读工具包`。
3. 点击命令旁的加号按钮。
4. 按下你想要的组合键。如果该组合已被其他命令占用，Obsidian 会给出提示。

插件不预设默认快捷键，以免覆盖你库里已有的快捷键。下面是一套实用的起点；macOS 的 `Cmd` 对应 Windows 与 Linux 的 `Ctrl`。

| 场景 | 命令 | 建议快捷键 |
| --- | --- | --- |
| 开始或继续阅读 | 下一元素 | `Cmd/Ctrl+Shift+J` |
| 结束当前这一段 | 为当前阅读主题评级 | `Cmd/Ctrl+Shift+Enter` |
| 保存选中文本 | 摘录选中内容 | `Cmd/Ctrl+Shift+E` |
| 制作卡片 | 从剪贴板制作卡片 | `Cmd/Ctrl+Shift+F` |
| 排期与阅读位置操作 | 当前元素操作… | `Cmd/Ctrl+Shift+A` |

先只用 **构建今日会话队列**、**下一元素**、**为当前阅读主题评级** 和 **摘录选中内容**。等流程熟练后再加其他命令。

## 阅读笔记与文章

在一篇已有的 Markdown 笔记上，从 **捕获或创建…** 选择 **导入剪藏（当前笔记）**。插件会写入排期 frontmatter，并在目标可用时把笔记移入配置的来源文件夹。

每次阅读时：

1. 从 **当前元素操作…** 选择 **跳转到阅读位置**，回到标记处。
2. 读到注意力下降或到达一个合适的停顿点为止。
3. 把值得回看的段落做成摘录。
4. 运行 **为当前阅读主题评级**，并把标记更新到光标位置。

移动标记就算作进度。启用停滞保护后，标记不动时间隔不会增长。

## 阅读 PDF 与书籍

从 **捕获或创建…** 选择 **新建来源**，选 **PDF** 或 **Book**，填入库内相对路径或绝对路径的 PDF 路径。然后使用：

- **当前元素操作…** 里的 **打开 PDF（工具包查看器）**，可打开库内或库外的 PDF。在工具栏输入页码后点 **保存阅读位置** 即可更新来源。
- **高级工具…** 里的 **将书籍拆分为章节**，粘贴页码范围列表后即可让各章独立排期。

评级时填入你停下的页码。章节排期使用章节的结束页，而不是整本书的总长度。

## 创建摘录与卡片

摘录本身就是另一个阅读主题。当某段内容还需要编辑、补上下文或继续思考时，用摘录最合适。
被摘录的段落会在来源里保持标记，摘录笔记在编辑视图与阅读视图中也有对应的背景色。可在 **设置 → 渐进阅读工具包 → 通用 → 摘录高亮颜色** 中改色。

卡片是可直接用于回忆练习的材料。卡片形式包括：

- 基础问答；
- 双向词汇对；
- `==高亮填空==` 删除；
- 图片命名卡片；
- 图片遮挡卡片。

卡片就是普通的 Markdown 笔记，只是记录了所用的卡片后端。在 **设置 → 渐进阅读工具包 → Flashcards** 中选择后端：

- **工具包（内置）**：把排期字段写进 frontmatter，用内置 FSRS 窗口复习。
- **通过 Flashcards 使用 Anki**：写入 `cards-deck` frontmatter，以及 `#card`/`#card-reverse` 或高亮填空语法，然后运行 **Flashcards: Generate for the current file**。牌组与 Flashcards 标签在 **通过 Flashcards 使用 Anki** 分区配置。同步时保持 Anki 与 AnkiConnect 运行。
- **Spaced Repetition（兼容）**：生成原有的带标签 Spaced Repetition Markdown 卡片。

该选择只影响新建卡片；已有卡片保留各自的后端。
图片遮挡块依赖工具包自带的渲染器，因此选择 Anki 时，这类卡片会保存为内置后端；基础、双向、填空与图片命名卡片可以正常导出到 Anki。

## 管理积压的队列

单篇笔记的操作放在 **当前元素操作…**，子树与积压处理放在 **高级工具…**。

- **设置优先级**：数字越小越优先。
- **推迟**：把单个主题移到更晚的日期。
- **推迟子树**：把一个来源及其后代一起后移。
- **宽限（分散逾期）**：把逾期主题摊到一个选定的时间窗口里。
- **子集复习**：从当前来源中挑出一个到期的后代。
- **已完成**：保留笔记，清除未来的工具包复习日期，并把它移出后续会话；Spaced Repetition 卡片同时退出其牌组。
- **重置**：把条目重新设为进行中并清除工具包排期历史；Spaced Repetition 卡片会作为新卡片回到牌组。
- **搁置**：排除你不再打算处理的内容。

## 整理知识树

从 **打开工具包视图…** 选择 **知识树**，可以创建分类、把材料拖到某个父节点下、调整同级顺序或重命名节点。用复选框多选来源、摘录或卡片，然后在批量操作栏里选择 **已完成** 或 **重置**。**选择可见项** 作用于当前已渲染的行，按住 Shift 点击可以选中区间。每一行也有自己的「已完成」与「重置」按钮。

关闭 **显示已完成材料** 后，已完成条目会从树上消失。它们的笔记仍留在库中，但未来的工具包排期会被清除；Spaced Repetition 卡片还会从其配置的牌组中移除。

同名（basename 相同）的文件仍然可见，但在改名之前不能作为父节点使用；这样可以避免链接指向错误的笔记。

## 日期格式

在 **设置 → 渐进阅读工具包 → 通用 → 日期格式** 中选择：

- `DD-MM-YYYY`，例如 `12-07-2026`；
- `MM-DD-YYYY`，例如 `07-12-2026`；
- `YYYY-MM-DD`，例如 `2026-07-12`。

**排期（手动日期）** 动作要求使用所选格式。`+3d`、`7d`、`-1d` 这类相对值在任何格式下都可用。

## 故障排查

**复习时看不到卡片**

确认卡片的 `ir_card_backend`。工具包卡片需要到期的 `next_review`；Anki 卡片在 Anki 中复习，不进入工具包队列；Spaced Repetition 卡片需要 Spaced Repetition 插件与配置好的卡片标签。

**Anki 卡片不同步**

确认 Reuseman 的 Flashcards 已启用、Anki 已打开、AnkiConnect 已安装，并在 Flashcards 设置中完成了授权。然后打开卡片笔记运行 **Flashcards: Generate for the current file**，或从工具包的高级工具中选择 **将 Anki 卡片与 Flashcards 同步**。

**复习命令提示 Spaced Repetition 正在启动**

重新加载 Obsidian，然后对队列中的卡片再次运行 **下一元素**，或直接使用 Spaced Repetition 自带的复习命令。

**PDF 无法在工具包查看器中打开**

确认 `pdf_path` 是有效的库内相对路径或绝对路径，或把 `pdf_vault_path` 指向库内文件。不支持 EPUB。

**知识树父节点不明确**

给其中一个同名文件改名，然后重新指定子节点的父级。

**日期被拒绝**

检查插件通用设置中的日期格式，或改用 `+1d` 这类相对值。
